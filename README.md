# Riley Saltzer Portfolio

Personal portfolio with separate Home, Work, About, and Contact pages.

## Publishing

In Settings → Pages, select **Deploy from a branch**, then **main** and **/(root)**, and save.
The GitHub Pages address is https://saltze1.github.io/Portfolio/ once deployment succeeds.

## Editing

Edit the HTML files for content and style.css for colors and layout. No build step is required.
The contact page offers Gmail, copy-email, and email-app links. It does not send messages itself.

The résumé is available as riley-saltzer-resume.pdf.
